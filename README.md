# Rolling Haven — Premium Caravan Rentals

![Static HTML Site](https://img.shields.io/badge/Site-Static%20HTML-blue.svg)

A premium caravan rental landing page showcasing Rolling Haven's fleet of caravans for road trips across India. Built with a focus on stunning UI/UX, smooth animations, and mobile responsiveness.

---

## 🚀 Tech Stack

- **HTML5** — Semantic, accessible markup structure.
- **CSS3** — Vanilla CSS with custom properties (CSS variables), modern layout techniques (Flexbox & Grid), and responsive design.
- **JavaScript (ES6+)** — Clean, modern interactive web scripts.
- **GSAP 3.12** — High-performance scroll-driven & interactive animations with ScrollTrigger plugin.
- **Lenis** — Smooth web scrolling experience.
- **Google Fonts** — Modern web typography using Cabinet Grotesk, Instrument Serif, and DM Sans.

---

## ✨ Features

- **Responsive Design** — Fully optimized across all screen sizes and mobile devices.
- **Custom Cursor** — Interactive custom cursor with magnetic button interactions.
- **Parallax & Scroll Effects** — Fluid scrolling animations powered by GSAP & Lenis.
- **Interactive Gallery** — Drag-scroll carousel with lightbox overlay.
- **Booking Form** — Dynamic live price calculator with direct WhatsApp integration.
- **FAQ Accordion** — Accessible, interactive expandable FAQ items.
- **Testimonial Carousel** — Auto-playing interactive customer reviews showcase.
- **Smooth Animations** — Hardware-accelerated micro-interactions and transitions.
- **Accessibility** — Built with focus-visible indicators, keyboard navigation support, ARIA attributes, and `prefers-reduced-motion` compliance.

## ⚡ Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/caravan-website.git
   ```
2. Open `index.html` directly in any web browser, OR launch using a local dev server (e.g. Live Server extension in VS Code).
3. Alternatively, deploy directly to any static hosting provider.

---

## 🌐 Deployment

- **GitHub Pages**: Go to **Settings > Pages > Source**, and select **Deploy from a branch** (main/root).
- Compatible with all major static hosting platforms: **Vercel**, **Netlify**, **Cloudflare Pages**.
